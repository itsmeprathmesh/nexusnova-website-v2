# Phase 3 — UX Strategy

## Information Architecture

```
Home → Problem-aware hero → Solutions → Workflow → Case Studies → CTA
├── Solutions
│   ├── Patient Intake Automation
│   ├── Appointment Management Systems
│   ├── Patient Follow-up & Recall
│   └── Lead Capture & CRM
├── Industries
│   ├── Dental Clinics
│   ├── Skin & Cosmetics
│   ├── Physiotherapy
│   ├── Eye Clinics
│   └── Multi-specialty
├── Case Studies
│   ├── [Clinic] – 40% fewer no-shows
│   └── [Clinic] – 3x more bookings
├── Resources
│   ├── Blog / Guides
│   ├── ROI Calculator (future)
│   └── FAQ
├── About
│   ├── Team
│   ├── Process
│   └── Philosophy
├── Contact
├── Privacy
└── Terms
```

## Navigation (Primary)
- Solutions (dropdown: Patient Intake, Appointments, Follow-up, CRM)
- Industries (dropdown: Dental, Skin, Physio, Eye, Multi-specialty)
- Case Studies
- Resources (dropdown: Blog, Guides)
- About

**Primary CTA**: "Book a Strategy Call" (pill button)

## Conversion Flow
```
Land → Problem resonance → Solution match → Case study proof → 
FAQ objection handling → Form with clinic context → Thank you + Calendar
```

## Key User Flows

### Flow 1: Clinic owner researching
1. Lands on homepage
2. Sees healthcare-specific problem (30% no-show rate)
3. Scrolls to solution modules
4. Clicks "See How It Works"
5. Sees animated workflow
6. Reads relevant case study
7. Clicks "Book a Strategy Call"
8. Fills clinic-specific form
9. Gets confirmation + calendar link

### Flow 2: Referred visitor
1. Lands on case study
2. Reads results
3. Clicks "Get Similar Results"
4. Fills contact form
5. Books call

## Mobile-First Planning
- Stack all sections vertically
- Full-width glass cards
- Bottom-fixed CTA on scroll
- Hamburger menu with all navigation items
- Touch-friendly form inputs (min 44px tap targets)
